# 存档列表性能优化（2026-10-28）

存档近邻配对先排除 300 秒窗口之外的日期，避免每个列表行重复启动 date 解析全部历史文件；保留精确匹配、300 秒阈值、跨午夜、三种时间戳格式及既有距离优先顺序。文件名提取使用 Bash 内建操作。

列表在一次菜单会话内复用双栈配对和元数据；每个协议的 IP 与地区一次读取。重新打开菜单清空缓存，仍可读取新存档及新内容。分页、快照和空地区回退行为保留。

相同 85 份 IPv6 存档的单次近邻配对，date 启动次数由 86 降至 4。本机 Windows Git Bash 耗时由 16,027 ms 降至 489 ms；Windows 的进程启动成本较高，Linux VPS 的实际耗时改善不能照搬。匹配文件一致。

完整离线回归 70 项通过；修改脚本通过 ShellCheck 与 Bash 语法检查。安装包包含同目录的 install.sh 和 ipqa.sh，解压后运行 `bash install.sh`，安装器优先使用本地脚本；历史数据及配置沿用原有安装流程。没有改动检测核心或检测项目，没有发布 GitHub Release。
